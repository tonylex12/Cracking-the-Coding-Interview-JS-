**Cracking the Coding Interview** es considerado la biblia para prepararse para entrevistas técnicas en empresas como Google, Facebook, Amazon, Microsoft y otras compañías tecnológicas de primer nivel.

- **Autora**: Gayle Laakmann McDowell

- **Sitio Oficial**: [www.crackingthecodinginterview.com](http://www.crackingthecodinginterview.com/)
- **Amazon**: [Ver en Amazon](https://www.amazon.com/Cracking-Coding-Interview-Programming-Questions/dp/0984782850)

Este repositorio contiene implementaciones detalladas en JavaScript de los problemas del libro, con:

- ✅ Código comentado en español
- ✅ Explicaciones paso a paso
- ✅ Análisis de complejidad temporal y espacial
- ✅ Múltiples enfoques de solución cuando es posible
- ✅ Ejemplos de uso

## 🛠️ Algoritmos y Técnicas Utilizadas

### Estructuras de Datos

- Hash Sets / Hash Maps
- Stacks
- Linked Lists
- Matrices

### Técnicas de Algoritmos

- **Two Pointers**: Runner technique, slow/fast pointers
- **Floyd's Cycle Detection**: Detección de ciclos en listas
- **Dummy Nodes**: Simplificación de construcción de listas
- **Frequency Counter**: Conteo de elementos
- **Run-Length Encoding**: Compresión de datos
- **In-Place Algorithms**: Modificación sin espacio extra
- **Matrix Manipulation**: Transpose, rotation

## 💻 Cómo Usar Este Repositorio

### Prerrequisitos

- Node.js (v14 o superior)
- Conocimientos básicos de JavaScript ES6+

### Ejecutar los Ejemplos

```bash
# Clonar el repositorio
git clone https://github.com/tonylex12/Cracking-the-Coding-Interview-JS-.git

# Navegar al directorio
cd craking-the-coding-interview

# Ejecutar un ejercicio específico
node 01_CHAPTER_ARRAYS_AND_STRINGS/01_01_exercise.js
```

### Estructura de Cada Archivo

Cada archivo de ejercicio contiene:

1. **Definición de estructuras de datos** (si es necesario)
2. **Solución(es) implementada(s)** con comentarios detallados
3. **Análisis de complejidad** (cuando aplica)
4. **Ejemplos de uso** con casos de prueba
5. **Salida esperada** en comentarios

## 📊 Análisis de Complejidad

Cada solución incluye análisis de:

- **Complejidad Temporal**: Big O notation del tiempo de ejecución
- **Complejidad Espacial**: Big O notation del uso de memoria

Ejemplo:

```javascript
/**
 * Complejidad:
 * - Tiempo: O(n)
 * - Espacio: O(1)
 */
```
